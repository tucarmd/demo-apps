AppVersion Demo

Demo for the capacitor-app-version plugin — shows getBuildInfo().source on screen.

Android

Download APK
Built by CI on every push to main.

Install on Android

  1. Scan the QR code with the phone camera (or tap Download APK on the phone).
  2. Open the downloaded app-version-demo.apk. Allow Install unknown apps for the browser if asked.
  3. Open AppVersion Demo. It should show APK.

Already installed an older build? It updates in place. If Android refuses (signature conflict), uninstall the old one first.
